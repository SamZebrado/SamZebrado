# Selected Projects

Selected software, interactive products, and agent tooling.

## Products & Interactive Systems

### [BeatGarden](https://github.com/SamZebrado/BeatGarden)

A playable rhythm-game and life-simulation PWA with deterministic simulation, local audio analysis, offline support, and regression-tested game systems.

**Signals:** TypeScript · PWA/offline lifecycle · Web Audio · deterministic state and persistence

[Repository](https://github.com/SamZebrado/BeatGarden) · [Play](https://samzebrado.github.io/BeatGarden/)

### [Transparent Floating Browser](https://github.com/SamZebrado/TransparentFloatingBrowser)

A Kotlin Android WebView overlay browser with multi-window transparency, edit/display modes, and Android 12+ touch-through handling.

**Signals:** Kotlin · Android overlays · WebView · system-constraint engineering

[Repository](https://github.com/SamZebrado/TransparentFloatingBrowser)

### [guiLaTeX](https://github.com/SamZebrado/guiLaTeX)

A visual document editor with element-level layout controls, shared IR-based export, and browser/PyQt prototypes.

**Signals:** browser and PyQt prototypes · IR-based export · layer controls · explicit prototype boundaries

[Repository](https://github.com/SamZebrado/guiLaTeX) · [Web demo](https://samzebrado.github.io/guiLaTeX/web_prototype/)

### [CheapLive](https://github.com/SamZebrado/CheapLive)

A privacy-first browser and Android face-capture prototype using local MediaPipe processing and procedural avatars.

**Signals:** MediaPipe · browser/Android integration · local camera processing · staged capability boundaries

[Repository](https://github.com/SamZebrado/CheapLive) · [Try face capture](https://samzebrado.github.io/CheapLive/src/face-tracking/)
