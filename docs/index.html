Transparent Floating Browser

Android overlay browser · Android 透明悬浮浏览器

把网页放在其他 Android 应用之上：多个透明 WebView 窗口可切换编辑／展示模式，并处理 Android 12+ 的触摸穿透与叠加透明度限制。核心功能已完成，当前仅做缺陷维护。

Place web pages above other Android apps. Multiple transparent WebView windows switch between edit and display modes, with opacity handling for Android 12+ touch-through constraints. Core functionality is complete; maintenance focuses on bugs.

真实设备验收仍待完成；触摸穿透受 Android 系统约束。
Real-device acceptance remains open; touch-through is subject to Android system constraints.

CheapLive

Local face capture · 本地面捕

不依赖昂贵设备的本地面捕：MediaPipe 在浏览器内处理画面，驱动程序化 Avatar，也可使用 Android Capture 在局域网传输面部参数。核心功能已完成，进入维护。

Low-cost face capture with browser-local MediaPipe processing and procedural avatars. An Android Capture client can send face parameters over the LAN. Core functionality is complete and in maintenance.

真实设备兼容性与捕捉质量仍待验证；不把规划中的 Live2D 渲染当作可用功能。

GrapePaper

Original-text-first reading · 原文优先的中文伴读

先读原文，再用中文梳理论证。手动确认已读选段，沿引用与来源短摘录核对出处，把模型解释与原始材料分开。当前正在开发，Zotero 选段桥接仍属实验版。

Read the original text first, then use a Chinese companion to unpack the argument. Explicit reading confirmation, citation trails and source excerpts keep model interpretation separate from source material. In active development; the Zotero excerpt bridge remains experimental.

实时 AI 需自配服务，真实模型推理尚未验证。Zotero 桌面兼容性不能由插件声明范围推定；不自动获取付费全文。
Live AI needs a configured service; real-model inference remains unverified. Zotero manifest ranges do not establish desktop compatibility. No automatic paywalled full-text acquisition.

  • React
  • TypeScript
  • PDF.js
  • excerpt provenance

guiLaTeX

Visual LaTeX layout · 可视化排版

把 LaTeX 排版变成可直接操作的画布。已完成的 Web V1 基线支持单页文字、图片、受限公式与约定格式导入／导出；更完整的可视化论文写作与真实 PDF 工作流是当前继续开发的方向。

A visual canvas for LaTeX layouts. The completed Web V1 baseline supports single-page text, images, a bounded equation subset and conforming import/export. The broader project is actively continuing toward a practical paper-writing and PDF workflow.

在线链接是静态展示；Web V1 编辑器在本机运行，不支持任意 LaTeX 文档。更完整的论文工作流是开发目标。
The online link is a static showcase. The Web V1 editor runs locally and does not import arbitrary LaTeX documents; the broader paper workflow is a development goal.

MCP Agent Task Bus

Persistent local MCP coordination · 持久化本地协调

一个稳定、不绑定提供商或宿主的本地 MCP 任务总线，以 SQLite 保存权威任务状态与事件，为独立 MCP 会话提供持久化交接。仅在 Codex 内编排时，原生能力已足够；真实跨宿主部署仍待验证。

A stable, provider- and host-neutral local MCP task bus with SQLite-authoritative tasks and events for persistent handoffs between independent MCP sessions. Native Codex capabilities suffice for Codex-only orchestration; real deployments across hosts remain unverified.
