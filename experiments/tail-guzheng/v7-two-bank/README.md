# v7：两琴真实参与候选的端到端扫弦模型

## 本次交付

v6保留为单琴A跨度对照。v7在同一段47.624807秒、22050 Hz单声道录音上，实际比较四种两琴音高方向和两种部分B可达跨度。最终两琴各有6个独立共享响应，不是只画出第二台琴。

最终共享音色版：**NRMSE 0.550716，相关0.834693，SNR 5.18145 dB**。v6单琴A跨度为0.546859、0.837224、5.24249 dB。本次双琴拟合稍差，不能为了两琴要求把误差改写成改善。

这是样本内拟合，不是独立验证、真实尾巴运动恢复、演奏真实性判断或生物可行性证明。没有把原录音混入合成声音。

## 视频证据与几何假设

实际查看了原视频接触拼图和12.2秒参考帧。可见两组弦、琴内顺序和相向边缘；B部分被画面裁掉，狗和衣物遮挡尾巴高度的弦点。无法可靠读出完整21+21根弦、具体调律、方向、全弦点、3D接触或端点距离。

因此沿用并明确标注为假设：

- B琴有序坐标0…20，A琴26…46，20到26之间为不发声空隙。
- 每台21弦、D五声音阶映射。空间位置与音高索引分开记录。
- 所有42个空间点保留，只有B最右边缘接空隙再接A最左边缘。
- 不把两个六音块贴在一起，不在内侧弦之间传送，也不要求扫遍42弦。
- 只拟合继承的六个音域索引5…10及其45模态；扫过其他弦时明确允许完全空过，不给它们增加音源。

+方向表示音高索引沿空间x增大；−方向相反。B+/A+在跨琴边界是B高音端接A低音端，反向扫时相反。四种方向都是候选，不能声称视频确定了方向。

## 六个有限候选与速度限制

速度上限仍为50弦距/秒，没有暗中调高。半周期上限从v6的0.90秒**显式放宽到2.00秒**，允许较大跨度慢慢扫过。这是新搜索假设，不是视频实测节律。

五次轨迹峰值速度为1.875×跨度/T，所以最短半周期由同一限速自动得出。

| 两琴六音域 | +/+ | [4.5,36.5] | 1.2000 | 12 | 0.582927 | 2396 |
| 两琴六音域 | +/− | [4.5,41.5] | 1.3875 | 12 | 0.617463 | 2369 |
| 两琴六音域 | −/+ | [9.5,36.5] | 1.0125 | 12 | 0.583887 | 2441 |

B反向时x=15对应索引5（约147Hz），x=14对应索引6（约164Hz）；A正向x31…36对应索引5…10。部分B候选没有强迫两琴六音域都可达。

每个候选在完整解析半周期族中以10毫秒端点网格搜索路线。目标为过弦起音证据得分，扣每半周期2.5及0.2×((T−1.2)/1.2)²的弱时长先验；后者是公开的搜索取舍，不是动物运动定律。

六候选分别做8轮、1初始化共享音色粗拟合，再只对粗筛最佳的+/+候选做18轮、2初始化精化，得到0.550716。不把仅粗筛的其他候选当作已充分优化，因此不是全局最优证明。+/+与−/−为反射等价，粗拟合差异只有数值误差；选+/+只是代表，不是识别了琴的朝向。

## 端点到端点的数学硬约束

每个半周期u=(t−t_k)/(t_(k+1)−t_k)，S(u)=10u³−15u⁴+6u⁵。

- 正向x=L+(R−L)S(u)，反向x=R−(R−L)S(u)。
- S′(u)=30u²(1−u)²，对所有0<u<1严格正。
- 方向按半周期交替，内部不能停车、停留或反向。只在固定端点反向。
- 端点速度、加速度为0，拼接为C²连续；三阶导数可以跳变。
- 全录音时间轴包括静音间隔都连续，没有在录音恢复处重设位置。静音间隔的动作是模型假设，没有观测支持。

最终端点[4.5,36.5]，跨度32弦距，完整空间轨迹经过B坐标5…20、空隙、A坐标26…36。其中仅两琴的六个拟合音域可以发声。

32个计划半周期段覆盖音轨，音轨内31个完整；最后端点47.63秒，晚于音轨结束约5.193毫秒。实际T范围1.20…2.00秒，中位1.405秒；7段贴最短速度边界，1段贴最长边界。相邻两扫组成的周期频率约0.252…0.417Hz，中位0.345Hz。

最大速度50弦距/秒，最大加速度128.300弦距/秒²，最大jerk约1111.111弦距/秒³。没有长度或视频节律标定，不能说这种跨度、速度或节律符合真实狗尾巴。

## 两琴共享音色如何分开

每个真实bank×string拥有自己的9极点×所属模态的复系数，一个有符号实数力对应一次几何过弦。B和A同音高可有不同音色，但载频仍复用同一六音域45个模态频率；同频贡献在单声道中相干相加。

初态只有每个观测模态、每次录音恢复一次，不为两台琴重复增加同一初态。初态不任意分配给某一琴。

最终：

- 12组独立物理弦响应，共1620个实系数。
- 450个汇总初态实系数。
- 326个有符号力，其中B161个、A165个。
- 总2396个声学实参数；去掉每根物理弦各一个尺度规约，通常有效维度2384。
- 另有31个10毫秒网格上的内部端点时刻，45个沿用的频率和一个评估增益。
- 不再独立调整每个事件的时刻、每个模态相位或每次事件的音色。

主音轨不设非零力下限。|力|<0.05 RMS单位仅在可视化标成弱接触：B25个、A16个；不改变主音轨，也不把该阈值当作可闻测量。跨过未建模弦时直接零激励，符合允许空过的假设。

完整计划含864个空间过弦候选：326个建模且在有效录音段，414个有效段内未建模弦空过，124个处于录音静音间隔。空隙本身没有发声事件。

两琴相干分量会相消：B、A单独分量能量相对总音轨分别约0.674和0.536，两者相干交叉项约−0.272。它们不是可相加的真实声源贡献百分比，这一自由度不能被隐藏。初态分量能量比约0.0687。

## 录音静音、旧版和指标

接触余振到下一个录音静音处终止，恢复时有一次初态。v4/v5旧代码只遮掉静音样本而可保留旧接触余振到恢复后；v6/v7显式重置。这是除轨迹之外的模型差异。v4/v5还允许中途停顿和折返，不满足当前端点往返约束。

指标使用全部原录音样本，最佳有符号标量a=(y·s)/(s·s)，NRMSE=||y−as||/||y||，SNR=−20log10(NRMSE)，相关系数使用未缩放合成波形。播放WAV沿用该增益，没有单轨峰值归一化，也没有截幅。

### 接旧公开v4/v5预处理管线

旧公开管线的字段与本接口直接兼容，但仅运行preprocess还不够，必须再运行fit_comparison以生成上述三个v4分析文件。以下OLD、V7、WORK分别代表旧公开代码目录、新v7代码目录和一个新的私有工作目录；请替换为实际路径。

```bash
python OLD/src/preprocess.py --input authorized.wav --work-dir WORK
python OLD/src/fit_comparison.py --work-dir WORK
python V7/fit_two_bank_sweeps.py --source WORK/input.wav --v4 WORK/v4 --out WORK/v7
python V7/render_two_bank.py --parameters WORK/v7/shared_parameters.json --out WORK/v7/v7_two_bank_shared_parameter_render.wav
python V7/audit_two_banks.py --directory WORK/v7 --source WORK/input.wav
```

如果音频需要静音分段，在第一条命令增加`--intervals intervals.json`。预处理会转换声道、采样率和PCM格式，所以后续`--source`**必须使用WORK/input.wav**，不能换回采样率或声道不同的原始输入。三个v4分析文件无需字段转换，且必须由这同一份预处理音频生成。

最后的audit命令会生成`WORK/v7/trajectory_visualization.json`及数值审计，供新v7双琴页面读取。它本身不导出HTML；**旧公开代码的export_demo.py不兼容v7参数结构**，不能直接作为新双琴展示入口。新展示导出脚本另行接入，不应把旧展示CLI标为已自动支持v7。

原视频、原音频、原Z和分析数组均不在公开包中。算法仍限于本案六音域及声明的几何假设，换输入须核对，不应把任意新输入标作原案例。

## 可视化接口

trajectory_visualization.json保留完整解析轨迹和42点映射，50Hz全时间轴运动，以及所有过弦的bank/note_index/coordinate/time/strength/status。20Hz模态帧由参数重渲染：

- families.shared_B、shared_A：各953×45，按metadata.modes[j]分出bank×string，绝不是先把同频两琴合并后伪分琴。
- families.shared：相干相加后的总包络。
- families.initial_state：未归属某琴的初态包络。

这些是模型复包络的绝对值，不是源音FFT、源Z或实测琴振幅。候选表和各候选参数保留；本次只交共享音色主音轨，不另外增加自由事件响应对照或无限优化。
