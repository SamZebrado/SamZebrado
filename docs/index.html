CheapLive

本地面捕与 Avatar；整合透明悬浮浏览器展示。面捕＋悬浮浏览器整合。

Browser-local face capture and procedural avatars, integrated with TransparentFloatingBrowser for Android overlay display.

Interactive demo / 互动演示互动演示 · 免安装 ↗
界面与说明 / Preview & notes界面与说明

不依赖昂贵设备的本地面捕：MediaPipe 在浏览器内处理画面，驱动程序化 Avatar，也可使用 Android Capture 在局域网传输面部参数。核心功能已完成，进入维护。

Low-cost face capture with browser-local MediaPipe processing and procedural avatars. An Android Capture client can send face parameters over the LAN. Core functionality is complete and in maintenance.

展示工作流整合独立的 TransparentFloatingBrowser，由这个 Android 工具把网页形象叠加在其他应用之上；纯网页自身不提供原生悬浮窗。

The display workflow integrates the separate TransparentFloatingBrowser Android tool to overlay the web avatar above other apps. The web page itself does not provide native Android overlays.

真实设备兼容性、捕捉质量与整合后的端到端体验仍待验证；不把规划中的 Live2D 渲染当作可用功能。
Real-device compatibility, capture quality and the integrated end-to-end experience remain unverified. Planned Live2D rendering is not available.

实时面捕 · Live face capture ↗：需允许摄像头并支持 WebGL；建议在系统浏览器中打开。云端浏览器的 WebGL 初始化失败不代表所有设备均不可用。
Requires camera permission and WebGL; try a system browser. A WebGL initialization failure in a cloud browser does not establish failure on every device.

我的贡献：选择把独立的透明悬浮浏览器整合进展示工作流；AI 承担大量实现。已有演示与界面检查不等于实机捕捉或整合验收。
My contribution: choosing to integrate the separate floating browser into the display workflow; AI contributes substantial implementation. Demo and interface checks do not establish real capture or integration acceptance.
